# Diabetes_Prediction
A machine learning web application that predicts whether a person is likely to have diabetes based on basic health parameters.

## Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- KNN → Regression
- Streamlit (UI and deployment)
